# 設定リファレンス

各プロジェクトのルートに `.ollama-mcp.toml` を置きます。ファイルが無くても動作します — 実質的に必要なのは `[gate]` だけで、それ以外にはすべて実用的なデフォルトがあります。

設定は**読み込み時に検証されます**。未知のキーや型の合わない値があると、ファイル名とキー名を示してサーバーが停止します。

```
/path/to/project/.ollama-mcp.toml: [gate] has no option 'timeuot_s'
/path/to/project/.ollama-mcp.toml: [limits] max_iterations must be int, got bool
```

黙ってデフォルトに落ちて三回目の委譲で気づく、という事態を避けるための設計です。設定ファイルは BOM 付き UTF-8 でも問題ありません。

---

## `[gate]` — 検証ゲート

**このサーバーで唯一、安全に推測できない設定です。** 委譲された編集のたびに実行され、失敗すればロールバックとエスカレーションになります。

| キー | 型 | デフォルト | 説明 |
|---|---|---|---|
| `commands` | `list[list[str]]` | `[]` | ワークスペースルートで実行するコマンド。終了コードが 0 以外なら失敗。 |
| `timeout_s` | `int` | `180` | コマンド 1 本あたりのタイムアウト（秒）。 |
| `autodetect` | `bool` | `true` | `commands` が空のとき、言語ネイティブのチェックにフォールバックする。 |

```toml
[gate]
commands = [
  ["ruff", "check", "--quiet", "."],
  ["python", "-m", "pytest", "-x", "-q", "tests/unit"],
]
timeout_s = 180
```

ゲートは**速く**保ってください。編集のたびに走り、失敗時はローカル再試行の後にもう一度走ります。

コマンドは `shell=False` で実行されるため、シェルの展開やパイプは使えません。

コマンドが見つからない場合（設定ミス、あるいは MCP サーバーが起動された PATH にそのツールが無い場合 —— シェルの PATH とは違うことがよくあります）は `UNVERIFIED` として報告され、ゲートは**失敗**します。実行されなかったチェックは、合格したチェックではありません。以前はこれを「スキップ」として合格扱いにしていたため、何も検証していないゲートが `gate: pass` を返していました。

`commands` は**引数リストのリスト**です。`[["ruff", "check", "."]]` と書いてください。`["ruff check ."]` のような平坦な書き方は、読み込み時にエラーになります。

自動検出の対象: `ruff`（`pyproject.toml` か `*.py` がある場合）、`npm run typecheck` または `npx tsc --noEmit`、`cargo check`、`go build ./...`。

`commands` の設定有無にかかわらず、変更されたファイルの構文チェック（`.py` と `.json`）は常に実行されます。無料で、言語に依存せず、ローカルモデルが最も起こしやすい壊し方を捕まえます。

## `[models]` — モデルのティア

| キー | 型 | デフォルト | 説明 |
|---|---|---|---|
| `fast` | `str` | `"qwen2.5-coder:7b"` | 調査と単一箇所の編集向け。 |
| `deep` | `str` | `"qwen3-coder:30b"` | 複数箇所にまたがる編集向け。数倍遅い。 |
| `fast_num_ctx` | `int` | `16384` | fast ティアのコンテキスト長。 |
| `deep_num_ctx` | `int` | `32768` | deep ティアのコンテキスト長。 |
| `keep_alive` | `str` | `"10m"` | Ollama がモデルを常駐させる時間。 |
| `temperature` | `float` | `0.1` | 機械的な作業なので低く保つ。 |

環境変数 `OLLAMA_MCP_FAST_MODEL` と `OLLAMA_MCP_DEEP_MODEL` が設定ファイルより優先されます。リポジトリを触らずにモデルを差し替えられます。

> **`num_ctx` についての注意。** Ollama のデフォルトは 4096 で、超過分は**黙って切り捨てられます**。ローカルモデルが自信たっぷりに間違った編集を返す原因として、これが最も多いものです。本サーバーは常に明示的に送ります。値を上げる場合、KV キャッシュがモデルの重みと VRAM を奪い合うことを忘れないでください。

## `[limits]` — 上限値

| キー | 型 | デフォルト | 説明 |
|---|---|---|---|
| `max_iterations` | `int` | `12` | 1 タスクあたりのローカルモデルのステップ数上限。 |
| `request_timeout_s` | `int` | `900` | Ollama への 1 リクエストのタイムアウト。 |
| `max_receipt_chars` | `int` | `4000` | **現在未使用**（予約）。レシートの長さは `server.py` 側で個別に切り詰められます。 |
| `max_file_bytes` | `int` | `400000` | これを超えるファイルは行範囲指定でしか読めない。 |
| `max_local_retries` | `int` | `1` | ゲート失敗後に許すローカル再試行の回数。 |

## `[sandbox]` — パスの閉じ込め

| キー | 型 | デフォルト | 説明 |
|---|---|---|---|
| `deny` | `list[str]` | `.git`, `.env`, 鍵ファイル, `node_modules` ほか | ブロックするディレクトリ名・ファイル名・拡張子。 |
| `allow_write_outside_git` | `bool` | `false` | **現在未使用**（予約）。ワークスペースルートの外への書き込みは、この値に関係なく常に拒否されます。 |

ルールは 3 通りの照合をします。パスの構成要素との完全一致（`node_modules`）、ファイル名との完全一致（`.env`）、拡張子との一致（`.pem`）です。

照合は大文字小文字を区別せず、Unicode 正規化の違いも吸収します。`deny = ["設定"]` は NFC 表記でも NFD 表記でも効きます。

`deny` を設定しても、**ワークスペースルートの外に出られない**という保証は別枠で常に有効です。

未使用と書かれたキーも設定ファイルに書いて構いません（検証は通ります）が、挙動は変わりません。

## `[i18n]` — 言語

| キー | 型 | デフォルト | 説明 |
|---|---|---|---|
| `language` | `str` | `"auto"` | `"auto"` \| `"en"` \| `"ja"` |

環境変数 `OLLAMA_MCP_LANG` が優先されます。

`auto` は呼び出しごとに指示文から判定し、判定できなければマシンのロケールを見ます。詳細と、翻訳されないトークンの一覧は [japanese-environment.md](japanese-environment.md) を参照してください。

## トップレベル

| キー | 型 | デフォルト | 説明 |
|---|---|---|---|
| `ollama_host` | `str` | `"http://127.0.0.1:11434"` | Ollama の接続先。 |

環境変数では `OLLAMA_HOST_URL`、次いで `OLLAMA_HOST` が参照されます。スキームが無い場合は `http://` が補われます。
